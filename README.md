# Локальный инференс LLM: от понятий до тюнинга на своём ПК

Книга на русском о том, как большие языковые модели работают «под капотом» и как запускать их на своём железе:
- токены и трансформер;
- prefill и decode;
- память и квантование;
- MoE и KV-кэш;
- спекулятивное декодирование;
- сэмплинг и вызов инструментов;
- методика бенчмарка;
- выбор модели под железо.

**Читать онлайн:** https://luckystrker.github.io/local-llm-inference-book/

Начать можно с [введения и карты книги](00-README.md). Источники — в [sources.md](sources.md): более 120 лекций, книг, статей и видео с аннотациями. История рецензирования и редактуры — в [REVIEW.md](REVIEW.md).

## Как устроено
- Главы — markdown-файлы `NN-*.md`. Диаграммы — Mermaid прямо в тексте.
- Графики — SVG в `figures/`, их генерируют скрипты `figures/src/*.py` (matplotlib). Все данные на графиках расчётные, по формулам из книги.

  Пересобрать: `MPLBACKEND=Agg python3 figures/src/build_all.py`.
- Сайт собирается [mdBook](https://github.com/rust-lang/mdBook) (`mdbook build`) и публикуется GitHub Actions на GitHub Pages.
